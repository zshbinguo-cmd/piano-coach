# 音阶陪练

弹钢琴音阶和琶音时，用设备麦克风实时听错音的小网页。适合原声钢琴（立式、三角），不需要 MIDI。

在线使用：https://zshbinguo-cmd.github.io/piano-coach/

- 选好调、类型和八度数，点“开始听”，从第一个音弹起
- 弹错马上提示应该弹什么，改对了再往下走
- 弹完一遍给出错音、漏音和节奏均匀度
- 双手同向（相隔八度）弹时选“只看音名”

声音全部在本机浏览器里处理，不会上传。练习记录只存在当前设备上。

iPad：用 Safari 打开网址，点“分享”→“添加到主屏幕”。

## 文件

- `index.html`：页面和练习逻辑
- `detector.js`：起音检测和音高判断
- `synth.js`：合成钢琴声，用于“演示”按钮和测试
- `启动音阶陪练.command`：在 Mac 上不联网时双击本地运行
